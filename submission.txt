=== CARA MENJALANKAN SKRIP UTAMA ===
1. Pastikan Anda berada di root direktori proyek.
2. Buat dan aktifkan virtual environment (opsional namun disarankan):
   > python -m venv venv
   > venv\Scripts\activate
3. Instal dependencies yang dibutuhkan:
   > pip install -r requirements.txt
4. Jalankan pipeline utama:
   > python main.py
   (Sistem akan secara otomatis mengeksekusi ekstraksi, transformasi, dan proses load ke CSV, PostgreSQL, dan Google Sheets).

=== CARA MENJALANKAN UNIT TEST & COVERAGE ===
1. Pastikan pustaka testing telah terinstal:
   > pip install pytest pytest-mock pytest-cov
2. Untuk menjalankan unit testing:
   > pytest tests/
3. Untuk melihat laporan Test Coverage (mencapai 94%):
   > pytest tests/ --cov=utils --cov-report=term-missing
